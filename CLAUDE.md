# Project conventions

## Stack

- Plain static HTML and CSS; no framework, package manager, or build step.
- The landing page lives in `project/index.html`.

## Conventions

- Keep markup semantic and accessible, and make layout work on mobile and desktop.
- Keep styles close to the page until the project needs shared styles.
- Do not invent a project name, features, or product claims while the capstone idea is undecided.
- Avoid adding dependencies unless a confirmed project need justifies them.

## Verification

- Open `project/index.html` in a browser to check the page.
- Run `git diff --check` before committing.
